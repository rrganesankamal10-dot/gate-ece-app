# GATE ECE Companion

This is a complete Flutter project, including the Android build folders —
you do NOT need Flutter installed on your computer to get an APK.

## How to get your APK (same flow as KamalShare)

1. Create a new empty repository on GitHub.
2. Upload this entire folder into it (keep the folder structure as-is).
3. Go to Codemagic, connect that new repository, same as you did for KamalShare.
4. Start a build using Codemagic's default Flutter workflow.
5. Download the APK once the build finishes, send it to your phone, and install it.

## If Codemagic's build fails

This Android setup was assembled by hand (not machine-generated by the
Flutter SDK, since Flutter isn't available in the environment that built
this), so there's a small chance a Gradle/Android version mismatch causes
a build error on first try. If that happens, paste me the exact error
from the Codemagic build log and I'll fix the specific file it's
pointing at — these are one-line config fixes, not a rebuild from
scratch.
